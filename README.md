# 방송대 공지 텔레그램 알리미

한국방송통신대학교 전체 공지에서 중복을 제외한 최신 40개를 15분마다 확인합니다. 새 공지가 발견되면 분류, 제목, 작성자, 작성일, 본문의 간단한 요약과 원문 링크를 텔레그램으로 보냅니다.

## 처음 한 번만 설정하기

1. 텔레그램에서 `@BotFather`를 찾아 `/newbot`으로 봇을 만들고 토큰을 받습니다.
2. 만든 봇과 대화를 열어 `/start`를 보냅니다.
3. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates`를 열고 `chat` 아래의 `id` 값을 확인합니다.
4. 이 폴더의 `start-setup.cmd`를 더블클릭합니다. 설정이 성공하거나 오류가 발생해도 창이 바로 닫히지 않습니다.
5. 봇 토큰과 채팅 ID를 입력합니다.

Windows에서 실행 여부를 물으면 내용을 확인한 뒤 실행을 선택합니다. `start-setup.cmd`도 실행되지 않는 경우, 이 폴더의 주소 표시줄에 `powershell`을 입력하고 다음 명령을 실행합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

설정 순간에 이미 존재하는 40개 공지는 알리지 않고 기준점으로만 저장합니다. 그 뒤 올라온 새 공지만 전송합니다.

## 확인과 관리

- 테스트 알림: `start-test-telegram.cmd`를 더블클릭
- 수동 확인: `knou-notifier.ps1`
- 실행 기록: `notifier.log`
- 자동 실행 해제: `uninstall-task.ps1`

`config.json`에는 봇 토큰이 들어 있으므로 다른 사람에게 보내거나 공개 저장소에 올리지 마세요.

## 동작 특성

- PC가 켜져 있고 인터넷에 연결된 동안 작동합니다.
- 한 번 실행할 때 목록 페이지 몇 개만 읽으므로 PC 부하는 매우 작습니다.
- PC가 꺼져 있던 동안 새 글이 40개를 넘으면 오래된 일부 공지는 놓칠 수 있습니다.
- 공지 본문을 읽지 못한 경우에도 제목과 원문 링크는 알립니다.
